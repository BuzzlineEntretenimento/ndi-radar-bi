# Radar de Mercado — Núcleo da Ideia

Este repositório hospedará o dashboard de inteligência de mercado e monitoramento de perfis do Instagram da NDI.

## Publicação

Adicione os arquivos `index.html`, `media.js` e `.nojekyll` na raiz do repositório. Em Settings > Pages, selecione **Deploy from a branch**, branch `main`, pasta `/ (root)`.

O painel apresenta retratos estáticos dos perfis analisados, não dados em tempo real. Conteúdos publicados neste repositório público poderão ser visualizados por qualquer pessoa.
